# A qué configuración de logros aplica cada caso del corpus léxico.
#
# La expectativa de un caso depende de los logros: `//#1.5,3` sólo se cumple con
# Floats I prendido, y `[Error:?|2]` sólo con el Ternario apagado. Un caso cuyos
# requisitos no se cumplen en la corrida se SALTEA, no falla: que un logro esté
# apagado es una configuración legítima del compilador, no un defecto.
#
# Formato, un caso por línea:
#
#     <directorio>/<archivo> | <logros que deben estar PRENDIDOS> | <APAGADOS>
#
# Los requisitos viven acá y no adentro de cada caso porque las expectativas del
# corpus son posicionales (`//#lexema,linea`, y la línea del EOF sale de cuántos
# saltos tiene el archivo): agregar un renglón de metadatos a un caso correría
# todas sus líneas y lo rompería.
#
# Un caso que no figura acá aplica a cualquier configuración.
