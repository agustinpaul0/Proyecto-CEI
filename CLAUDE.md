# CLAUDE.md

La memoria operativa de este proyecto vive en `AGENTS.md`. Se importa entera acá abajo.

Precedencia ante conflicto: `AGENTS.md` y `guias/*.md` (normas de este proyecto) ganan siempre
sobre cualquier skill de `.claude/skills/`, que son genéricas y de terceros.

Los documentos de `guias/` son **normativos** (qué hacer, para el agente); los de `documentacion/`
son **explicativos** (por qué, para el profesor). Cuatro nombres de archivo se repiten entre las dos
carpetas (`arquitectura.md`, `especificacion-lexica.md`, `testing.md`, `manejo-de-errores.md`): al
citar uno, incluir siempre la carpeta.
